# Kourosh (کوروش)

> بنیان‌گذاری یک مدل زبانی فارسی از صفر — قدم به قدم.

## درباره‌ی پروژه

**Kourosh** یک مدل زبانی (Language Model) است که از پایه ساخته می‌شود،
با هدف درک عمیق معماری Transformer و ساخت یک دستیار هوشمند فارسی‌زبان.

نام پروژه از **کوروش بزرگ**، بنیان‌گذار امپراتوری هخامنشی، الهام گرفته شده است.

## ساختار پروژه

```
Kourosh/
├── data/               # داده‌های آموزشی
│   ├── raw/            # داده‌های خام
│   └── processed/      # داده‌های پردازش‌شده
├── src/                # کد اصلی
├── notebooks/          # تحلیل و آزمایش
├── checkpoints/        # مدل‌های ذخیره‌شده
├── tests/              # تست‌ها
└── requirements.txt
```
